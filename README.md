# java-escape-room

객체지향 프로그래밍 팀 프로젝트 — Java Swing 방탈출 게임

공중도시의 시간 기관실(1번 방) → 왕실 계승의 방(2번 방) → 혈월의 예배당(3번 방)을 제한 시간 안에 탈출하는 포인트 앤 클릭 방탈출 게임입니다.

## 실행

- VS Code에서 프로젝트 폴더를 열고 `src/common/MainFrame.java` 의 `main` 을 실행합니다. (JDK 17 이상)
- 어느 폴더를 열어도 `resources` 폴더를 자동으로 찾습니다.
- 모니터 크기에 맞춰 창 전체(방 · 글꼴 · 팝업)를 최대 1.4배까지 키워서 실행합니다.
- 각 방은 `Room1Panel` / `Room2Panel` / `Room3Panel` 의 `main` 으로 따로 실행해 볼 수도 있습니다.

## 플레이 방법

1. 시작 화면 "시간의 서가"에서 항해 일지를 꺼내고, 승선 명부에 이름을 쓰고 서명하면 1번 방으로 들어갑니다.
   (아래 메뉴: 난이도 · 이어하기 · 명예의 전당 · 설정 · 도움말 · 종료)
2. 돋보기 표시가 있는 곳을 클릭해 조사하고, 단서와 아이템으로 퍼즐을 풉니다.
3. 오답이면 체력이 줄고, 체력이나 시간이 0이 되면 게임 오버입니다.
4. 세 방을 모두 탈출하면 점수 · 등급이 나오고 명예의 전당에 기록됩니다.

| 키 | 기능 |
|---|---|
| ESC | 일시정지 · 설정 |
| H | 힌트 |
| M | 메모장 |
| I | 가방의 최근 아이템 보기 |
| F5 | 저장 |

## 방 구성

| 방 | 이름 | 퍼즐 | 담당 패키지 |
|---|---|---|---|
| 1번 | 공중도시의 시간 기관실 | 압력 밸브, 기관 정지 패널 | `room1` |
| 2번 | 왕실 계승의 방 | 초상화 장식장, 왕가의 문장, 원탁의 자리, 비밀 출구 | `room2` |
| 3번 | 혈월의 예배당 | 촛불, 금고, 지팡이 조합, 마력 회로 | `room3` |

- 2번 → 3번 방은 어둠 속 문이 열리고 지하 돌계단을 내려가는 이동 연출이 있습니다.

## 주요 기능

- **핵심 규칙**: 제한 시간, 체력(하트), 난이도(쉬움 / 보통 / 어려움), 시간 경고
- **진행 보조**: 단계별 힌트(사용 시 시간 차감), 현재 목표 상자, 진행도 바, 가방(인벤토리), 메모장, 조사 지점 돋보기 표시
- **메뉴**: 일시정지 + 설정 창, 도움말, 저장 / 이어하기, 결과 화면(점수 · 등급), 명예의 전당(랭킹)
- **연출**: 방별 UI 테마(황동 / 왕실 / 혈월), 방 이동 연출과 도착 자막, 오답 시 붉은 화면 + 흔들림, 효과음
- **개발자 모드**: 설정 → [개발자 모드] (비밀번호 `2048`) — 퍼즐 건너뛰기, 이전 / 다음 방, 현재 방 처음부터, 체력 회복, 시간 +5분. 사용한 판은 랭킹에 등록되지 않습니다.

## 프로젝트 구조

```
src/
  common/   공통 게임 시스템 (MainFrame, GameManager, RoomPanel, 상단 바, 가방, 팝업, 저장, 랭킹, 테마 등)
  mgr/      강의 구조의 Manageable / Manager<T> / Factory<T>
  room1/    1번 방 (공중도시의 시간 기관실)
  room2/    2번 방 (왕실 계승의 방)
  room3/    3번 방 (혈월의 예배당) + docs/ (3번 방 문서)
tests/
  room3/    3번 방 테스트 코드
resources/
  common/ room1/ room2/ room3/   이미지 · 효과음
  data/hints.txt                 방별 단계 힌트
data/        저장 · 랭킹 · 설정 파일 (실행 시 자동 생성, Git 제외)
```

### 사용한 객체지향 개념

- **상속 / 추상 클래스**: 모든 방은 추상 클래스 `RoomPanel` 을 상속, 팝업은 `DialogBox` 를 상속
- **다형성**: `GameManager` 는 몇 번 방인지 몰라도 `RoomPanel` 타입으로 목표 · 힌트 · 저장을 처리
- **인터페이스 + 옵저버 패턴**: `GameListener` 로 상단 바 · 목표 상자 · 가방이 게임 상태 변화를 자동 반영
- **제네릭 + Manageable / Manager / Factory**: `Manager<T extends Manageable>` 로 아이템 · 힌트 · 랭킹 관리, `readAll(파일, Hint::new)` 로 txt 파일을 객체로 읽기
- **싱글톤**: `GameManager`, `GameSettings`, `SoundManager`, `HintMgr`
- **enum**: `Difficulty`, `RoomTheme`

## 공통 시스템 통합 내역

각 방은 팀원이 만든 화면 · 퍼즐 코드를 그대로 두고, 공통 시스템에 연결하는 코드만 더했습니다. 방 코드 안의 연결 부분은 `[통합]` 주석으로 표시되어 있습니다.

- **공통 (`src/common`, `src/mgr`)**: 게임 진행 관리, 상단 바, 목표 상자, 가방, 일시정지 · 설정, 힌트, 메모, 저장 / 이어하기, 결과 화면, 랭킹, 방별 테마, 방 이동 연출, 돋보기 표시, 개발자 모드, 화면 자동 확대
- **시작 화면**: 1번 방의 `BookStartPanel`("시간의 서가") 연출을 시작 화면으로 사용하고, 아래에 메뉴 막대를 붙임
- **1번 방**: `RoomPanel` 상속 · 오답 / 해결 / 아이템을 공통 시스템에 연결 · 게임 중에는 공통 상단 바와 가방 사용
- **2번 방**: `RoomPanel` 상속 · 퍼즐 오답 시 체력 감소 · 단서 / 퍼즐 창을 테두리 없는 팝업으로 · 알림창을 방 테마 모양으로 · 배경 이미지 교체(`왕실_계승의_방_배경.png`)
- **3번 방**: `RoomPanel` 상속 · 촛불 / 금고 오답 시 체력 감소 · 조사 화면 왼쪽 위 [← 돌아가기] · 팝업을 테두리 없는 테마 팝업으로 · 테스트 코드를 `tests/room3` 로 이동
